HOW TO PREVIEW
Unzip, keep the folder structure as-is, and double-click index.html.
Pages: index.html (home), art/index.html, community/index.html, squidbird/index.html (the squidbird.io page).
All images live in images/ (and squidbird/images/ for the Squidbird page).
To publish: drag this whole folder into Netlify (the _redirects file handles squidbird.io).
